# Jogo de Adivinhação de Palavras

Projeto desenvolvido para a atividade de encerramento da disciplina de Desenvolvimento de Aplicações Web I.

## Integrante
- Luiz Otávio Gonzaga de Souza Lima

## Como jogar
1. O computador escolhe uma palavra aleatória.
2. Digite uma letra no campo indicado.
3. Clique em **Tentar** ou pressione **Enter**.
4. Letras corretas aparecem na palavra.
5. Letras incorretas diminuem o número de tentativas.
6. Descubra a palavra antes de acabar as seis tentativas.
7. Clique em **Nova partida** para jogar novamente.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Funcionalidades
- Escolha aleatória entre mais de 10 palavras.
- Exibição da palavra escondida por traços.
- Verificação de letras corretas e incorretas.
- Lista de letras utilizadas.
- Bloqueio de letras repetidas.
- Limite de seis tentativas.
- Mensagens de vitória e derrota.
- Botão para iniciar uma nova partida.
- Uso da tecla Enter para enviar uma tentativa.
